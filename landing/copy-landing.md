## SECCIÓN 7 · FAQ
> **Elementor:** Section fondo blanco, acordeón. Este contenido es crítico para AEO — las IAs van a responder estas preguntas con tu contenido.

### HEADLINE (H2, centrado, #3a4655)
```
Preguntas frecuentes
```
> *EN:* `Frequently Asked Questions`

---

**P1: ¿Funciona con Commerce7?**
```
Sí. BetterSEO está diseñado específicamente para Commerce7. Se conecta
con tu Tenant ID, sincroniza todo tu catálogo de productos de forma automática
y genera las páginas SEO correspondientes sin necesidad de configuración
manual por producto.
```

**P2: ¿Y con eCellar?**
```
También. BetterSEO soporta eCellar usando tu API key. El proceso de
sincronización y generación de metadata es el mismo que con Commerce7.
```

**P3: ¿Necesito saber de código para instalarlo?**
```
No. BetterSEO es un plugin de WordPress estándar. Lo instalás desde el
panel de administración de WordPress, ingresás tus credenciales de
Commerce7 o eCellar, y el plugin hace el resto automáticamente.
Si preferís que lo haga el equipo de Gorilion, el setup profesional
tiene un costo único de $199.
```

**P4: ¿Es compatible con Rank Math y Yoast?**
```
Sí, BetterSEO es compatible con ambos plugins. Detecta cuál tenés activo
y trabaja junto a él, desactivando únicamente los módulos que generarían
conflictos con las páginas de producto para evitar metadata duplicada.
```

**P5: ¿Qué es Open Graph y por qué importa para mi winery?**
```
Open Graph es el protocolo que define cómo se ve tu contenido cuando
alguien comparte un link en redes sociales, WhatsApp, iMessage o Slack.
Sin Open Graph, el link aparece como texto plano. Con Open Graph,
aparece con la imagen del vino, el nombre y una descripción. Esto aumenta
significativamente el click-through rate y refuerza la imagen de marca.
```

**P6: ¿Qué son los AI engines y por qué me afectan?**
```
AI engines son herramientas como Google AI Overviews, ChatGPT (SearchGPT),
Perplexity o Claude que responden preguntas directamente en lugar de
mostrar links. Cuando alguien pregunta "cuál es el mejor Pinot Noir de
Sonoma", estas IAs generan una respuesta usando páginas con datos
estructurados correctamente. Si tu sitio no tiene schema de producto,
tus vinos no aparecen en esas respuestas.
```

**P7: ¿Mis productos tienen que estar publicados en Commerce7 para aparecer?**
```
Sí. BetterSEO sincroniza los productos disponibles en tu catálogo de
Commerce7 o eCellar. Productos archivados o sin disponibilidad de venta
online no se incluyen en el feed ni en las páginas SEO generadas.
```

**P8: ¿Cada cuánto se actualiza el catálogo?**
```
BetterSEO sincroniza automáticamente tu catálogo en intervalos regulares.
También podés forzar una sincronización manual desde el panel de
administración de WordPress cuando lo necesités — por ejemplo, al lanzar
una nueva añada o actualizar precios.
```

**P9: ¿Puedo cancelar en cualquier momento?**
```
Sí. No hay contratos de permanencia. Podés cancelar tu suscripción
en cualquier momento desde tu panel de cliente.
```

**P10: ¿Qué plataformas de e-commerce soportan además de Commerce7 y eCellar?**
```
Por ahora BetterSEO está optimizado específicamente para Commerce7 y
eCellar, que son las plataformas de e-commerce más utilizadas por wineries
en Estados Unidos. El soporte para otras plataformas está en nuestro roadmap.
```
